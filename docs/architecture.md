# 架构与协作

## 目标与计划

人确定问题、资源与停止条件。Goal记录长期目标，Plan记录当前分解；Spec把需求连接到可检查的验收点。开始新会话时先读入口和当前任务，再核对实际资产，避免仅从聊天摘要猜测状态。

## 运行器与Hook

冻结阶段复制选定代码、输入与任务配置并计算SHA。前置检查重新核对快照。运行阶段使用参数数组启动进程，保存标准输出与退出记录。后置检查确认声明产物齐全。任务执行成功与科学验收使用不同证据：没有模型评价时，不能将执行成功写成科研结论成立。

Hook在本发布版中是Python运行器调用的确定性检查函数。它不声称自动安装在Codex或其他宿主的全部工具入口。需要宿主事件钩子时，应在该宿主按实际接口连接，并保留触发日志。

## 缓存与恢复

缓存身份由输入、代码与配置共同决定。相同字节可支持复用，人员身份、状态及训练暴露等语义条件还需要独立审计。失败保留原始回执，不延长原预算、不覆盖旧失败，也不重复启动健康或已完成任务。

## 多Agent职责

规划者负责合同和共享接口；执行者只修改分配范围；核验者从真实产物复算。各工作线可以并行做数据清点、实现和材料整理，共享GPU仍按依赖和资源授权排队。会话数不等于独立证据数。

## 内外研究循环

内环围绕具体假设完成冻结、执行与核验。外环比较证据、更新解释并选择下一问题。若未解决的是输入资格，应先设计能区分该解释的受控比较，而非继续扩大模型搜索。停止与暂停由任务合同、预算和人确定。

## Skill 插件与MCP

Skill提供可复用方法，插件组织工具入口，MCP传递工具模式、参数和返回。发布版提供连接协议，不复制第三方技能全文，也不附带模型服务或通用MCP服务器。可将本运行器封装为宿主工具，再把真实回执交回Agent分析。
