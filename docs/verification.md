# 验证与适用范围

发布检查包括：冻结资产或任务清单被修改时拒绝执行；正常任务产生完整回执；失败或超时保留退出信息；已有状态的任务不被无提示重复计算；越界产物路径被拒绝；独立指标程序拒绝重复人员和非法概率。测试结果见GitHub Actions或本地unittest输出。

合成示例验证的是工程路径。它不能证明MDD识别能力、临床意义、模型冷重放或Harness相对手工工作的效率提升。真实研究应提供对应的人员隔离、输入资格、冻结模型、完整概率、按人统计、原设备重放与人工解释。

本仓库从课程项目整理发布，运行器的跨平台通用化是本次发布工作。历史Linux作业监督器、GPU队列与MDD适配器不随本包自动部署；项目历史结果不因本包测试通过而获得新的科学资格。
