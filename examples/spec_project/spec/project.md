# 项目规格入口

## 目标与范围

初始化仅建立管理结构。根据本项目用户请求填入实际目标、交付范围、成功行为和条件依赖；尚未确定的语义写入 requirements，不假定已确认。

## 当前权威与工作顺序

- 当前需求及验收：[requirements.json](requirements.json)
- 当前快照：[status.md](status.md)
- 可执行任务：[tasks.md](tasks.md)
- 解释与变更：[decisions.md](decisions.md)

先读本页和当前需求，再处理对应任务所需的实现与证据。历史实验和旧计划保留，若与当前合同不一致须说明版本和适用范围。
